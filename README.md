# Diwali Homework

This repository contains the scanned **SNAI assignment** submitted as part of the Diwali homework.

## Contents

The assignment PDF includes notes and questions covering:

- Semiconductor manufacturing, process nodes, and chip supply chains
- Linux and Unix command-line usage
- Shell commands, environment variables, and the `PATH`
- Operating-system concepts such as processes, CPU scheduling, and memory
- Compilation, machine code, and executable binaries
- Git concepts and common Git workflows
